# Services API — Version 2018-11-01

> Source: https://api.planningcenteronline.com/docs/apps/services/versions/2018-11-01

This is the version landing page for the **Services** app at API version `2018-11-01`. It contains the changelog for this version plus an index of every resource ("vertex") exposed by the Services API.

- Base URL: `https://api.planningcenteronline.com/services/v2`
- Available versions: `2018-11-01` (current), `2018-08-01`
- Machine-readable spec: [OpenAPI Description](https://api.planningcenteronline.com/services/v2/open_api/2018-11-01)

## Changelog (2018-11-01)

Changed the `/people` endpoint to respect the "Can view people not on My Teams" permission setting found on the Services People page.
